# Installation Guide - Justidea WebP Converter

## 📦 Quick Installation

### Step 1: Upload Module

1. Copy the entire `justidea_webpconverter` folder to `/modules/`
2. Ensure correct permissions:
   ```bash
   chmod -R 755 modules/justidea_webpconverter
   ```

### Step 2: Install via Back Office

1. Log in to PrestaShop **Back Office**
2. Navigate to: **Modules → Module Manager**
3. Search for "Justidea WebP Converter"
4. Click **Install**
5. Click **Configure**

### Step 3: Configure Settings

1. **Enable WebP conversion:** Yes (enabled by default)
2. **WebP Quality:** 80% (recommended)
3. **Auto-convert on upload:** Yes (recommended)
4. **Keep original images:** Yes (recommended for fallback)
5. **Conversion method:** Auto (recommended)

### Step 4: Convert Existing Images

1. In the module configuration page
2. Click **"Convert All Existing Images"** button
3. Wait for the conversion to complete
4. Check statistics to verify conversion

## 🎨 Integrate with Hummingbird Theme

### Option 1: Use Smarty Function (Recommended)

Edit Hummingbird product templates:

**File:** `templates/catalog/_partials/product-images-modal.tpl`

```smarty
{* BEFORE: *}
<img src="{$image.large.url}" alt="{$image.legend}">

{* AFTER: *}
{webp_picture src=$image.large.url alt=$image.legend class="img-fluid"}
```

### Option 2: Use Smarty Modifier

**File:** `templates/catalog/_partials/miniatures/product.tpl`

```smarty
{* BEFORE: *}
<img src="{$product.cover.medium.url}" alt="{$product.cover.legend}">

{* AFTER: *}
<img src="{$product.cover.medium.url|webp}" alt="{$product.cover.legend}">
```

### Option 3: Automatic (No Template Changes)

The module automatically detects and serves WebP images via JavaScript.

**No changes required!** Just enable the module.

## 🚀 Performance Optimization

### Preload Critical Images

Add to `templates/_partials/head.tpl`:

```html
<link rel="preload" as="image" type="image/webp" href="{$urls.shop_domain_url}/img/logo.webp">
```

### Lazy Loading

All images generated by `{webp_picture}` automatically include `loading="lazy"`.

### HTTP/2 Server Push (Optional)

In `.htaccess`:

```apache
<IfModule http2_module>
    Header add Link "</img/logo.webp>; rel=preload; as=image; type=image/webp"
</IfModule>
```

## ⚠️ Troubleshooting

### Problem: "No conversion method available"

**Solution:**
```bash
# Install GD with WebP support
sudo apt-get install php-gd
sudo service apache2 restart

# OR install ImageMagick
sudo apt-get install php-imagick
sudo service apache2 restart
```

### Problem: "Permission denied" errors

**Solution:**
```bash
# Set correct permissions
sudo chown -R www-data:www-data img/
sudo chmod -R 755 img/
```

### Problem: WebP images not displaying

**Solution:**
1. Clear PrestaShop cache: **Advanced Parameters → Performance → Clear Cache**
2. Clear browser cache: Ctrl+Shift+Delete
3. Verify WebP files exist: `ls img/p/**/*.webp`

### Problem: Batch conversion timeout

**Solution:**
```bash
# Increase PHP max_execution_time
php_value max_execution_time 600
php_value memory_limit 256M
```

Or run conversion via CLI:
```bash
php modules/justidea_webpconverter/cli/batch-convert.php
```
